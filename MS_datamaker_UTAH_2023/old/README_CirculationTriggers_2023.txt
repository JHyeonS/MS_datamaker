README.CirculationTriggers_2023.txt


This data archive includes the DAS triggers detected during the 16A-16B circulation tests that took place in July 2023. This dataset was acquired by the FOGMORE R&D project (Fiber Optic MOnitoring for Reservoir Evolution), Utah FORGE R&D Project 3-2417.

Report Lead Author : Ismael Vera Rodriguez (Silixa)
Co-authors 	   : David Podrasky, Thomas Coleman, Carlos Maldaner, Yuanyuan Ma, Jonathan Ajo-Franklin
README File        : Ismael  Vera Rodriguez, assembled May 5th, 2025
Project Lead:      : Jonathan Ajo-Franklin (Rice)


Instrumentation: Data utilized were from the FOGMORE 16B DAS dataset (Silixa Carina) and the 78B DAS dataset (Silixa iDAS v2). Fiber optic cable design and installation information are available on GDR "Utah FORGE Project 3-2417: Well 16B(78)-32 Fiber-Optic Cable Installation Report" https://gdr.openei.org/submissions/1603

Methods: Data is raw in units of nanostrain rate.

Files:
-----------
SEGY.tar.gz                                              : Compressed tar.gz of folder containing all the individual trigger files in segy format
FORGE_DAS_Circulation2023_ChannelMapping.csv             : Channel coordinates for each trace in the SEGY files
README.CirculationTriggers_2023.txt                      : This file
